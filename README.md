# VVcat Audio Cutter 2.1

一个在浏览器本地运行的音频剪辑工具。保留原项目的波形框选、多片段编辑、缩放和总览，同时加入真实 MP3 / Ogg Vorbis 编码及 Ableton Live 风格的深灰橙色工作区，使用猫队长音乐站的猫图标。

## 使用

### 直接打开单文件版

发布包中的 `dist/AudioCutter-standalone.html` 可以直接用现代浏览器打开。脚本、样式、MP3 / Vorbis 编码器均已内嵌，不需要联网或安装依赖。

从源码生成单文件版：

```bash
npm run build
```

需要 Node.js 18 或以上；构建和测试脚本均无需 `npm install`。

### 本地开发或静态部署

项目根目录可以直接作为静态网站部署到 GitHub Pages、Cloudflare Pages、Nginx 等。必须保留 `css/`、`js/`、`vendor/` 目录结构，不依赖 CDN、服务端或额外的跨源隔离响应头。

例如，在仓库根目录启动本地服务器：

```bash
python -m http.server 8080
```

打开 `http://localhost:8080`。多文件源码版应通过 HTTP / HTTPS 访问，避免浏览器对 `file://` 加载 Worker / WASM 的限制。直接双击时请使用独立 HTML 版。

也可以执行 `npm run build` 后将整个 `dist/` 目录作为发布目录。构建会同时生成普通多文件版和独立 HTML。

## 导出能力

| 格式 | 编码与参数 | 适用场景 |
| --- | --- | --- |
| WAV | 16 / 24 bit PCM；32 bit IEEE float | 后期制作、音效归档、无损编辑 |
| MP3 | LAME，128 / 192 / 256 / 320 kbps CBR | 分享、试听、通用播放 |
| OGG | Vorbis，Q3 / Q5 / Q7 / Q10 VBR | 游戏音频、循环素材 |

- 输出采样率支持跟随项目、44.1 kHz、48 kHz；支持单声道和立体声。
- 可选择 5 / 10 / 50 / 100 ms 的边缘淡入淡出，默认关闭，便于保留循环素材边缘。
- 没有片段时导出整段音频；存在片段时只导出勾选的片段。全部取消勾选后禁用导出。
- 单个片段直接下载；多个片段打包成 ZIP。同名片段自动添加编号，文件名中的不兼容字符会替换为下划线。
- MP3、OGG 和 WAV 都实际编码对应格式，不是仅修改扩展名。
- 导出过程中显示进度，允许取消；完成后保留再次下载链接。若浏览器阻止自动下载，可以点击该链接。

## 剪辑与操作

- 导入音频，或将文件拖放到页面；也可点击「试用示例」生成八秒示例音频。
- 在波形空白处拖拽创建片段；移动片段调整位置，两侧手柄调整边界。
- 「添加片段」从当前播放位置创建最长五秒的片段。
- 列表支持重命名和毫秒级时间输入，输入有效时间后即时更新波形。
- 单击片段选中；双击片段或点击列表播放键试听；循环按钮控制片段循环。
- 撤销和重做覆盖创建、删除、拖拽、边界调整、重命名和勾选，最多保存 80 个状态。
- Ctrl / ⌘ + 滚轮以鼠标位置为中心缩放；缩放按钮和滑块以当前视图中心缩放。
- 总览区左右拖动平移视图，上下拖动缩放；单击跳转播放位置。
- 提供浅色 / 深色主题、移动端布局和可键盘操作的控制项。
- 左右侧栏均可独立收起。左侧为项目浏览器，右侧为导出设置；顶部专注模式可同时收起两侧，并在退出时恢复先前布局。布局偏好自动记忆，隐藏的侧栏退出键盘焦点顺序。

| 快捷键 | 操作 |
| --- | --- |
| Space | 播放 / 暂停；控件获得焦点时保留其原生键盘行为 |
| Ctrl / ⌘ + O | 导入音频 |
| Ctrl / ⌘ + N；Ctrl / ⌘ + S | 新建项目；立即保存项目 |
| Ctrl / ⌘ + 反斜杠 | 收起 / 展开左侧项目栏 |
| Ctrl / ⌘ + Shift + 反斜杠 | 收起 / 展开右侧导出栏 |
| Ctrl / ⌘ + Z | 撤销 |
| Ctrl / ⌘ + Shift + Z；Ctrl / ⌘ + Y | 重做 |
| A | 添加片段 |
| Delete / Backspace | 删除选中片段 |
| + / − / 0 | 放大 / 缩小 / 显示全部 |
| ← / → | 后退 / 前进 5 秒 |

## 批量命名

勾选列表中需要修改的片段，点击「批量命名」。可设置名称前缀、起始编号、编号位数和分隔符；默认三位编号。留空前缀会生成 `001`、`002`、`003`，设置前缀「挥砍」会生成 `挥砍_001`、`挥砍_002` 等。

命名按当前列表的时间顺序进行，仅修改勾选的片段。对话框提供实时预览；超出设定位数时自动扩展，不会回绕编号。一次撤销 / 重做覆盖整批命名。导出时添加所选格式的扩展名。

## 项目

左侧「新建项目」或顶部「新建」可创建独立项目。顶部项目名称可以直接编辑。新建或切换前会先保存当前项目，左侧本地项目列表可随时切回。

在支持 IndexedDB 的浏览器中，源音频、片段名称与边界、勾选状态、导出设置及播放 / 缩放位置自动保存在当前网站的浏览器存储中；刷新会恢复上次项目。撤销历史只在当前编辑会话中保留。

项目保存在当前浏览器和网站地址下，不上传到服务器，也不跨设备同步。清除该网站的浏览器数据会同时清除这些项目。浏览器无法提供持久存储时会明确显示「会话保存」，此时只在当前页面打开期间保留项目。

应用图标直接复用 [vvcat-music-radio 的原图](https://github.com/Chen-JjinG/vvcat-music-radio/blob/main/assets/logo/logo.png)，位于 `assets/vvcat-logo.png`。独立 HTML 版同样内嵌该图标。

## 性能与数据处理

MP3、OGG、WAV 和 ZIP 操作均在 Web Worker 中进行。片段 PCM 使用可转移缓冲区传给 Worker，避免结构化复制；解码后的音频用于波形显示，避免重复完整解码。重采样使用 `OfflineAudioContext`。

片段列表使用稳定的行节点，拖动片段时只更新当前行。时间轴缩放、标尺和统计通过 `requestAnimationFrame` 合并。总览区使用单套 Pointer Events，消除原版重复鼠标事件造成的平移 / 缩放冲突。更换文件时使用加载序号阻止旧异步结果覆盖新项目，并清理播放资源和下载 URL。

## 边界说明

- 导入格式取决于浏览器自身解码能力；扩展名可选不代表浏览器一定支持其内部编码。建议使用当前版本 Chrome / Edge / Firefox / Safari。WAV / MP3 通常兼容性更广。
- 对于可识别的 RIFF WAV，8–96 kHz 范围内保留其采样率作为项目采样率；其他输入格式统一解码为 44.1 kHz 项目音频。界面明确显示项目采样率，导出「跟随项目」指该采样率。
- MP3 在非常见项目采样率下自动适配为 44.1 kHz，以支持界面提供的全部比特率，界面同步显示这一适配。
- 输出最多两个声道；多声道输入会按浏览器标准扬声器布局混音。试听音量独立于导出音量。
- WAV 是解码后重新编码，不能恢复源有损文件已丢失的细节。选用更高位深也不会增加源音频已有信息。
- OGG 品质对应的大小是近似估计；静音和不同内容的实际大小会不同。MP3 编码存在帧填充，实际时长可能略多于片段时长；严格循环素材建议使用 WAV / OGG。
- 完整音频会解码到内存，当前不是面向数小时或多 GB 音频的流式编辑器。WAV 不支持大于 4 GB 的 RF64 文件。
- 项目与主题偏好保存在当前网站的本机浏览器中；持久保存是否可用以界面状态为准。
- 两侧栏展开状态也只保存在本机浏览器。

## 验证

```bash
npm test
npm run build
```

测试运行生产编码 Worker 和仓库内 WASM，检查 PCM 正负值、位深、时长、声道顺序、MP3 / Vorbis 文件结构、编码器复用、淡入淡出和中文文件名 ZIP。安装 FFmpeg / ffprobe 后还会独立识别并解码生成文件，确认其编码、采样率、声道、比特率和非静音输出。还包含自动编号、溢出编号、项目恢复与存储隔离测试。另有独立版打包回归测试，验证内嵌 Worker 与 WASM 完整、无需外部脚本或样式。
